# GTA VI: KBM → Xbox gamepad

Клиент не отправляет в GTA мышь/клавиатуру как MKB (игра их не поддерживает).
Он 60 раз в секунду отправляет обычный gamepad-кадр. Поэтому «ПК-клавиша» ниже
означает: **какую клавишу нажать, чтобы получить соответствующую кнопку Xbox**.

Профили (переключение `F4`, `F` автоматически переключает ON FOOT ↔ VEHICLE):

`ON FOOT` → `VEHICLE` → `AIRCRAFT` → `BICYCLE`

## ON FOOT

| Действие | Xbox | Клавиша у нас |
|---|---|---|
| Движение | левый стик | `WASD` |
| Обзор | правый стик | мышь |
| Спринт | LS click | `Left Shift` |
| Укрытие | RB | `Q` |
| Стрельба | RT | `ЛКМ` |
| Прицеливание / взаимодействие | LT | `ПКМ` |
| Взаимодействие | Y | `E` (и `F` для входа в транспорт) |
| Ближний бой (лёгкий/тяжёлый) | X | `R` / `O` (оба дают X; heavy/light решает игра) |
| Присесть | B | `Left Ctrl` |
| Прыжок / лазание | A | `Space` |
| Обзор назад | R3 | `C` |
| Карта | View | `Z` (tap) |
| Задача / мини-карта | D-pad Down | `Z` (hold) |
| Телефон | D-pad Up | `↑` или средняя кнопка мыши |
| Взрывчатка | D-pad Right | `G` (tap) |
| Быстрый бросок | RB | `G` (hold) |
| Меню снаряжения | LB | `M` (hold) |
| Смена оружия | Y | колесо мыши / `1–9` |
| Приблизить/отдалить прицел | D-pad Up/Down | `Shift` + колесо |
| Пауза | Menu | `P` |

`Q` в пешем режиме — укрытие. Радио-колесо `Q` работает в профиле VEHICLE
(там `Q` = D-pad Left), потому что на пешком обе функции конфликтуют.

## VEHICLE

| Действие | Xbox | Клавиша у нас |
|---|---|---|
| Поворот | левый стик X | `A` / `D` |
| Обзор | правый стик | мышь |
| Газ | RT | `W` |
| Тормоз / назад | LT | `S` |
| Ручной тормоз | A | `Space` |
| Стрельба (drive-by) | RB | `ЛКМ` |
| Сигнал | LS click | `E` |
| Вход / выход | Y | `F` |
| Пригнуться / фары | B | `X` / `H` |
| Радио | D-pad Left | `Q` |
| Телефон | D-pad Up | `↑` / средняя кнопка |
| Взрывчатка | D-pad Right | `G` (tap) |
| Пауза | Menu | `P` |

## AIRCRAFT

| Действие | Xbox | Клавиша у нас |
|---|---|---|
| Тангаж / крен | левый стик | `WASD` |
| Тяга вверх / вниз | RT / LT | `W` / `S` |
| Рыскание | X / B | `A` / `D` |
| Обзор | правый стик | мышь |
| Стрельба | RB | `ЛКМ` |
| Вход / выход | Y | `F` |

`W/S` одновременно дают тангаж и тягу, `A/D` — крен и рыскание: так таблица
GTA одновременно использует стик и кнопки.

## BICYCLE

| Действие | Xbox | Клавиша у нас |
|---|---|---|
| Педали | RT | `W` |
| Тормоз | LT | `S` |
| Поворот | левый стик X | `A` / `D` |
| Bunnyhop | B | `Space` |
| Спринт | A | `Caps Lock` |
| Сойти | Y | `F` |
| Обзор | правый стик | мышь |

## Особые случаи

* `G`: tap → D-pad Right (детонация), hold >250 мс → RB (быстрый бросок).
* `Z`: tap → View (карта), hold >250 мс → D-pad Down (задача).
* `Shift` + колесо → D-pad Up/Down (зум). Обычное колесо → Y (смена оружия).
* `F` на пешком/в машине не только отправляет Y, но и переключает профиль.
  Для самолёта/велосипеда профиль выбирается вручную `F4`.
* Физический геймпад отключён, пока активен виртуальный пад (index 0).
