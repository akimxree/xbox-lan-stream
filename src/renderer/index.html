Прямой сегмент (ICS)

Раздайте интернет на Xbox с отдельного Ethernet-порта ПК. Тогда видео идёт по кабелю PC↔Xbox, минуя роутер. Требуются права администратора.

NAT fallback не раздаёт DHCP: на Xbox задайте вручную 192.168.137.2 / 255.255.255.0, шлюз 192.168.137.1, DNS 1.1.1.1. 

—

Качество и буфер

Только для игр с локом 30 fps. Добавляет ~1 исходный кадр задержки и crossfade-ghosting; выключено по умолчанию.

Это верхняя граница в SDP. Реальный битрейт задаёт энкодер консоли; xHome обычно упирается в ~15–25 Mbps для 1080p60.

FSR 3 Frame Generation для готового видео невозможен: нужны motion vectors из игры. 30→60 в клиенте не делаем — это даёт ghosting и +1 кадр задержки. Для GTA 6 включите performance-режим игры.
